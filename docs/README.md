## 구현 기능 목록

### 1. 로또 구입 금액을 입력받는다.
#### 1-1. 입력 받기
- [X] 로또 구입 금액을 입력받는다.
- [x] 구입 금액은 1,000원 단위로 입력받는다.(로또 한장 당 가격은 1000원)

**입력 예시**

```
구입금액을 입력해 주세요.
8000
```

---

#### 1-2. 로또 구입 금액 검증 + 파싱
- [x] 로또 구입 금액의 값이 유효한지 검증한다.
- [x] 검증된 로또 구입 금액을 int로 파싱한다.

- **예외 처리**
- [x] 입력이 비어있는 경우 `IllegalArgumentException` 발생 후 재입력 - parser 처리
  - 예: `""`, `" "`
  - 오류 메시지: `[ERROR] 로또 금액이 입력되지 않았습니다. 로또 금액을 입력해주세요.`
- [x] 입력값이 정수가 아닌 경우 `IllegalArgumentException` 발생 후 재입력 - parser 처리
  - 예: `"abc"`, `"3.5"`
  - 오류 메시지: `[ERROR] 로또 금액은 정수만 입력 가능합니다. 다시 입력해주세요.`
- [x] 입력값이 0하고 같거나 작은 수를 입력 받은 경우 `IllegalArgumentException` 발생 후 재입력 - 도메인 처리
  - 예: `"-5000"`,`"0"`
  - 오류 메시지: `[ERROR] 로또 금액은 양의 정수만 입력 가능합니다. 다시 입력해주세요.`
- [x] 입력값이 1000원 단위 입력이 아닌 경우 `IllegalArgumentException` 발생 후 재입력 - 도메인 처리
  - 예: `"4200"`,`"100"`
  - 오류 메시지: `[ERROR] 로또 금액은 1000원 단위로 입력해야 합니다. 다시 입력해주세요.`
---

#### 1-3. 금액에 해당하는 만큼 로또를 발행
- [x] 로또 구입 금액의 값만큼 로또를 발행한다.
- [x] 1에서 45 사이의 중복되지 않은 정수 6개로 발행한다.
  - `Randoms.pickUniqueNumbersInRange(1, 45, 6)` 사용;
- [x] 발행 후 모든 로또 번호를 출력한다.

**출력 예시**
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```
---

### 2. 당첨 번호를 입력 받는다.
#### 2-1. 입력 받기
- [x] 당첨 번호를 입력 받는다.
- [x] 입력 받는 당첨 번호는 1에서 45 사이의 중복되지 않은 정수 6개이다.

---
#### 2-2. 입력 받은 당첨 번호 분리
- [ ] 쉼표(`"\\s*,\\s*"`)를 기준으로 문자열을 분리한다.
- [ ] 각 숫자의 앞 뒤 공백을 제거한다. (정규식을 사용하면 trim() 미사용)
- [ ] 빈 문자열을 포함하여 모든 문자를 목록에 추가한다.
- [ ] 입력받은 당첨 번호는 중복되어선 안된다.
- [ ] 분리된 당첨 번호 목록을 반환한다.

**예외 처리**
- [ ] 입력이 비어있는 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `""`, `" "`
  - 오류 메시지: `[ERROR] 당첨 번호를 입력해 주세요. 다시 입력해주세요.`
- [ ] 당첨 번호가 6개보다 적다면 `IllegalArgumentException` 발생 후 재입력
  - 예: `"2,4,5,7,22"`,`"1,2,a,7,-1"`,`"-1,4,2,ㅁ,!"`
  - 오류 메시지: `[ERROR] 당첨 번호가 6개보다 작습니다. 다시 입력해주세요.`
- [ ] 당첨 번호가 6개보다 많다면 `IllegalArgumentException` 발생 후 재입력
  - 예: `"2,4,5,7,22,1,42"`,`"1,2,4,a,7,-1,42"`,`"@,#,-1,4,2,ㅁ,!"`
  - 오류 메시지: `[ERROR] 당첨 번호가 6개보다 큽니다. 다시 입력해주세요.` 
- [ ] 분리된 당첨 번호에 중복이 있다면 `IllegalArgumentException` 발생 후 재입력 (개별 당첨 번호 검증 + 파싱 후)
  - 예: `[1, 2, 3, 4, 4, 5]`,`[1, 2, 3, 43, 43, 5]`
  - 오류 메시지: `[ERROR] 당첨 번호는 같은 번호가 존재해서는 안됩니다. 다시 입력해주세요.`
---
#### 2-3. 개별 당첨 번호 검증 + 파싱
- [ ] 각 당첨 번호의 숫자가 유효한지 검증한다.
- [ ] 당첨 번호가 비어있으면 안된다.
- [ ] 당첨 번호가 정수가 아니면 안된다.
- [ ] 당첨 번호는 1 ~ 45이어야 한다.
- [ ] 검증된 당첨 번호를 int로 파싱한다.

- **예외 처리**
- [x] 당첨번호가 비어있는 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `" "`, `""`, `"   "`
  - 오류 메시지: `[ERROR] 당첨 번호를 공백없이 입력해주세요. 다시 입력해주세요.`
- [ ] 당첨번호가 정수가 아닌 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `"abc"`, `"3.5"`, `"!as"`
  - 오류 메시지: `[ERROR] 당첨 번호는 정수만 입력 가능합니다. 다시 입력해주세요.`
- [ ] 당첨번호가 1 ~ 45가 아닌 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `"46"`,`"48"`,`"52"`
  - 오류 메시지: `[ERROR] 당첨 번호는 1 ~ 45의 정수만 입력 가능합니다. 다시 입력해주세요.`

---

### 3. 보너스 번호를 입력 받는다.
#### 3-1. 입력받기
- [ ] 보너스 번호를 입력 받는다.
- [ ] 보너스 번호는 1 ~ 45 사이의 수이다.
- [ ] 보너스 번호는 당첨 번호 입력에 받은 수와 중복되면 안된다.

---

#### 3-2. 보너스 번호 검증 및 파싱
- [ ] 보너스 번호는 비어있으면 안된다.
- [ ] 보너스 번호는 정수가 아니면 안된다.
- [ ] 보너스 번호는 1 ~ 45이어야 한다.
- [ ] 보너스 번호는 당첨 번호와 중복되서는 안된다.
- [ ] 검증된 보너스 번호는 int로 파싱한다. 

**예외 처리**
- [ ] 보너스 번호가 비어있는 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `" "`, `""`, `"   "`
  - 오류 메시지: `[ERROR] 보너스 번호를 공백없이 입력해주세요. 다시 입력해주세요.`
- [ ] 보너스 번호가 정수가 아닌 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `"abc"`, `"3.5"`, `"!as"`
  - 오류 메시지: `[ERROR] 보너스 번호는 정수만 입력 가능합니다. 다시 입력해주세요.`
- [ ] 보너스 번호가 1 ~ 45가 아닌 경우 `IllegalArgumentException` 발생 후 재입력
  - 예: `"46"`,`"48"`,`"52"`
  - 오류 메시지: `[ERROR] 보너스 번호는 1 ~ 45의 정수만 입력 가능합니다. 다시 입력해주세요.`
- [ ] 당첨번호 안에 중복이 있다면 `IllegalArgumentException` 발생 후 재입력 
  - 오류 메시지: `[ERROR] 보너스 번호는 당첨 번호와 같은 번호가 존재해서는 안됩니다. 다시 입력해주세요.`

---

### 4. 당첨 결과 계산한다.
#### 4-1. 당첨 결과 계산
- [ ] 발행된 각 로또에 대해 당첨 여부를 판정한다.
- [ ] 각 로또 번호와 당첨 번호를 비교하여 일치하는 개수를 센다.
- [ ] 일치 개수에 따라 등수를 판정한다.
- [ ] 당첨 번호 + 보너스 번호와 로또 번호를 비교하여 당첨 결과를 계산한다.
  - 6개 일치 → 1등 (2,000,000,000원)
  - 5개 일치 → 보너스 번호 확인
    - [ ] 보너스 번호 포함 → 2등 (30,000,000원)
    - [ ] 보너스 번호 미포함 → 3등 (1,500,000원)
  - 4개 일치 → 4등 (50,000원)
  - 3개 일치 → 5등 (5,000원)
  - 2개 이하 → 당첨 없음
- [ ] 각 등수별 당첨 개수를 집계한다.
- [ ] 당첨 금액의 총합을 계산한다.

#### 4-2. 총 수익률 계산
- [ ] 구입 금액 대비 총 수익률을 계산한다.
- [ ] 수익률은 소수점 둘째자리에서 반올림한다.
---

### 5. 당첨 결과 출력
- [ ] 당첨 통계를 출력한다.
- [ ] 총 수익률을 출력한다.

**출력 예시**
```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

**실행 결과**
```

8000

[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

7

4개 일치 (50,000원) - 0개

5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
```
